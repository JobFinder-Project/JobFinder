# **Histórias do usuário**

## História de Usuário 1:
Como usuário do sistema, quero acessar minha conta com segurança e poder recuperar meu acesso caso esqueça a senha, para que eu não perca o histórico das minhas atividades.
#### Critérios de Aceitação:
1. O sistema deve permitir o acesso utilizando e-mail e senha previamente cadastrados.
2. O sistema deve identificar automaticamente se o usuário é um candidato ou uma empresa e direcioná-lo para o painel correto.
3. Caso o usuário esqueça a senha, ele pode solicitar um link de recuperação via e-mail.
4. O link de recuperação deve ter um prazo de validade (15 minutos) por questões de segurança.
5. O usuário deve conseguir encerrar sua sessão com segurança a qualquer momento.

## História de Usuário 2: 
Como candidato, quero manter meu perfil atualizado com minhas experiências, cursos e foto, para que as empresas conheçam melhor meu potencial profissional.
#### Critérios de Aceitação:
1. O candidato deve preencher dados como nome, telefone, educação, qualificações e idiomas no cadastro inicial.
2. Deve ser possível realizar o upload de uma foto de perfil para identificação visual.
3. O candidato pode editar qualquer informação do seu currículo digital a qualquer momento.
4. O painel principal do candidato deve exibir um resumo de suas informações e as vagas disponíveis.

## História de Usuário 3:
Como empregador, quero cadastrar minha empresa com dados oficiais e gerenciar nossa presença na plataforma, para que possamos atrair talentos qualificados.
#### Critérios de Aceitação:
1. A empresa deve fornecer nome, e-mail, CNPJ e telefone para o registro.
2. O sistema deve validar se o CNPJ informado é real e possui o formato correto.
3. A empresa pode adicionar uma biografia e o link do seu site oficial ao perfil.
4. O empregador deve ter a opção de excluir a conta da empresa, removendo todos os seus dados do sistema.

## História de Usuário 4:
Como candidato, quero buscar vagas de meu interesse e me candidatar a elas, para que eu possa participar de processos seletivos.
#### Critérios de Aceitação:
1. O candidato pode pesquisar vagas por nome ou por área de atuação através de uma barra de busca.
2. Ao selecionar uma vaga, o candidato deve ver todos os detalhes, requisitos e a empresa responsável.
3. O candidato pode se inscrever na vaga com um clique, desde que ainda não tenha se candidatado a ela.
4. O sistema deve permitir que o candidato visualize o status de suas candidaturas (Pendente, Aceito ou Rejeitado).
5. O candidato pode desistir de uma candidatura, removendo sua inscrição da lista da empresa.

## História de Usuário 5:
Como empregador, quero anunciar vagas com requisitos claros e gerenciar os candidatos inscritos, para que eu possa contratar o profissional ideal.
#### Critérios de Aceitação:
1. A empresa pode criar novos anúncios de emprego informando título, área, requisitos e anexando uma imagem ilustrativa.
2. O empregador pode pesquisar profissionais na plataforma baseando-se em sua formação acadêmica ou qualificações técnicas.
3. A empresa deve ter acesso a uma lista de todos os candidatos que se inscreveram em suas vagas.
4. O empregador deve poder alterar a situação de cada candidato para "Aceito" ou "Rejeitado", dando um retorno sobre o processo.

## História de Usuário 6:
Como candidato, quero filtrar as vagas por área de atuação ou palavras-chave, para que eu encontre rapidamente as oportunidades que melhor se adequam ao meu perfil.
#### Critérios de Aceitação:
1. O candidato pode pesquisar vagas digitando termos específicos na barra de busca.
2. O sistema deve apresentar uma lista de áreas profissionais (ex: Saúde, Tecnologia, Administração) baseada nas vagas abertas.
3. Ao selecionar uma área específica, a lista de vagas deve ser atualizada para mostrar apenas as oportunidades pertencentes a essa categoria.
4. Cada vaga listada deve exibir informações resumidas para facilitar a triagem visual pelo candidato.

## História de Usuário 7:
Como empregador, quero poder filtrar candidatos com base em qualificações e experiências específicas, para que eu possa encontrar os melhores candidatos para as vagas da minha empresa.
#### Critérios de Aceitação:
1. O empregador pode pesquisar profissionais utilizando termos relacionados à educação (ex: "Ensino Médio", "Graduação").
2. O sistema permite filtrar candidatos por qualificações específicas digitadas na barra de busca.
3. O empregador deve visualiza o perfil completo do candidato interessado antes de tomar uma decisão.

## História de Usuário 8:
Como empregador, quero ter um painel centralizado com as minhas vagas e inscritos, para que eu possa gerir o recrutamento de forma organizada.
#### Critérios de Aceitação:
1. O empregador deve poder visualizar todas as vagas publicadas pela sua empresa e o resumo de dados de cada uma.
2. O dashboard deve exibir as imagens das vagas e dos candidatos corretamente para carregamento rápido.
3. O empregador deve ter atalhos rápidos para criar novas vagas ou editar o perfil institucional.
   
## História de Usuário 9:
Como candidato, quero visualizar a página pública da empresa, para que eu possa conhecer a marca e ver todas as suas vagas abertas num só lugar.
#### Critérios de Aceitação:
1. O sistema deve exibir publicamente os dados da empresa selecionada.
2. A página deve listar automaticamente todas as oportunidades ativas publicadas por aquela empresa.
3. O candidato deve conseguir aceder a esta página clicando no nome da empresa nos detalhes de qualquer vaga.

## História de Usuário 10:
Como usuário, quero um canal de suporte disponível no sistema para tirar dúvidas técnicas ou relatar problemas.

## História de Usuário 11:
Como candidato, quero interagir com outros profissionais da área para trocar experiências e dicas sobre entrevistas e mercado local.
